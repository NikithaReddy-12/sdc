# GSDC GRIET Website

A rebuilt Skill Development Cell website inspired by the information architecture and clean event/team storytelling of the E-Cell IIIT-H reference site, while keeping GSDC's own identity, logo, colors and content.

## Run

```bash
npm install
npm run dev
```

## Pages
- `/` — animated public website
- `/admin` — local admin dashboard for editable events, present team, past events and team imagery

## Design direction
- Clean editorial landing page
- Large GSDC logo as the hero focal point
- Subtle motion, reveal animations, hover interactions and ambient background movement
- Separate present team, past events and past team/legacy sections
- Admin login and content editing preserved
